# Объекты и задачи

Небольшая CRM для стройки: постановщик ведёт площадки и задачи, исполнитель видит только свою работу и двигает её по цепочке статусов.

Стек: React, TypeScript, Vite, Supabase.

## Запуск

```bash
npm install
npm run seed
npm run dev
```

Приложение откроется на http://localhost:5173.

Проверка прав, уже после `seed`:

```bash
npm run check:security
```

Команда сначала смотрит миграцию и исходники, затем входит тремя демо-пользователями и пробует запрещённые запросы.

## Демо-вход

Пароли учебные, их можно передавать вместе с заданием.

| Кто | Почта | Пароль | Роль |
| --- | --- | --- | --- |
| Анна Соколова | anna.sokolova@example.com | Demo-Manager-2026 | постановщик |
| Иван Крылов | ivan.krylov@example.com | Demo-Executor-1 | исполнитель |
| Мария Лебедева | maria.lebedeva@example.com | Demo-Executor-2 | исполнитель |

В базе три площадки и пять задач: новая, в работе, на проверке, на доработке и принята. На ЖК «Северный» есть задачи и Ивана, и Марии: каждый видит только свои.

## Как защищены данные

Объекты закрыты политиками базы. Постановщик видит и меняет все. Исполнитель видит площадку, только если на ней есть его задача, и не может её изменить.

Задачи и история закрыты жёстче. У обычного пользователя нет права добавлять, менять и удалять эти строки. Работают три процедуры:

- `create_task` — постановщик создаёт задачу сразу в статусе «Новая» и пишет первую строку истории;
- `update_task` — постановщик меняет только название и описание;
- `transition_task` — проверяет, кто делает шаг и допустим ли он, затем меняет статус и дописывает историю.

Триггер не даёт записать задачу или историю в обход этих процедур. Историю нельзя изменить или удалить даже сервисным ключом: триггер отвергает такую операцию. Комментарий обязателен только когда постановщик возвращает задачу на доработку; пробелы не считаются.

Роль хранится в таблице `profiles`. Пользователь не может сам сделать себя постановщиком. Профиль создаёт только `service_role` через `bootstrap_profile`, её вызывает `npm run seed`.

Кнопки на экране повторяют те же правила, но не заменяют их. Чужой запрос к базе получает отказ.
